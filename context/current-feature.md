## Goals
<!-- Goals and requirements -->

- Fit-score ring with explicit color thresholds (below 50 red, 50–74 amber, 75+ green), matching the gap-severity palette used elsewhere.
- Small trend indicator near the fit score for re-runs of the same job post (e.g. "+12% since last run", up/down arrow); first-ever comparison for a job post omits it.
- Primary "Generate CV for this role" action near the top, distinct from "Re-run comparison" → goes to the CV Template Picker flow.
- "Re-run comparison" → recalculates against the *current* Skill Bank state and creates a **new** Comparison record (never overwrites the old one).
- Skill Gap Analysis list grouped into "Needs attention" (Missing/Below required, expanded by default) and "Met" (collapsed by default, explicit expand/show-all control) — each row clickable with a hover state, linking out to that skill's Skill Bank entry (pre-filled add if it doesn't exist, edit if it does).
- Rule-based Advice cards, each clickable with a hover state, deep-linking to the relevant action (skill-gap tip → Skill Bank add-entry flow, phrasing/bullet tip → CV Editor).
- Empty / Loading / Error states for the report (per `00-general.md`), consistent with the "Other list states" reference tiles visible in the mock.
