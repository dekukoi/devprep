## Goals
<!-- Goals and requirements -->

- Stat tiles (Total comparisons, Average fit, CVs, Postings tracked) — clickable with a hover state, linking to filtered list views (stub routes, screens not built yet).
- Recent Comparisons: fit-score ring cards (company/role, ring, date, a representative gap chip), "View all" link, per-section empty state.
- My CVs: row list (role + stale-field badge, target job post, version badge, edited-relative-time, pencil/copy/"..." actions), "View all" link, per-section empty state.
- "..." row menu: Rename, Change template, Export PDF, View versions, Delete (Delete opens a confirm dialog per the `CV Delete Confirmation` frame).
- Copy icon duplicates a CV, prompting for a new title (shares the rename dialog UI).
- "+ New comparison" modal: searchable Job Post picker (radio rows) → "Run comparison" → loading state → toast, per `Modal — New Comparison` / `Modal — New Comparison Loading`.
- First-run/zero-account empty state (`Screen — Dashboard Empty`): 3-step onboarding checklist instead of stats/lists, shown only when both comparisons and CVs are empty; each section still handles its own independent empty state otherwise.
