## Goals
<!-- Goals and requirements -->

- `Screen — CV Editor`: top bar (back, CV title + version badge, "Tailored to {job}" clickable subtitle link to the Job Post), Save/Export PDF actions, "Saved just now" status, a "Stale fields" toggle, and a "History" button; document canvas on the left, tabbed right rail (Suggestions only — Comments tab removed) on the right.
- Inline, contentEditable-style editing directly on the rendered CV document (not a separate structured form).
- Suggestions panel: Accept/Reject per suggestion — Accept updates the live draft immediately (collapses the card, decrements the counter badge) but does not create a new version by itself; zero-pending state shows a quiet "You're all caught up" illustration+message instead of an empty list.
- Explicit **Save** button (distinct from Export PDF) creates a new immutable `CVVersion` from the current draft; disabled/quiet when there are no unsaved changes. **Export PDF** implicitly saves first if there are unsaved changes, then renders/downloads.
- **Stale fields** toggle in the top bar globally shows/hides stale-field markers across the document; each stale marker has a hover/click tooltip explaining the Skill-Bank-vs-CV divergence with an opt-in "Sync to Skill Bank" action (never automatic).
- **Version History** panel/drawer: clicking a past version opens a **read-only preview** (not an instant swap) with its own explicit "Restore" action that copies that version's content into a **new** version.
- Skill chip row at the bottom of the document wraps/scrolls fully instead of clipping.
- Reached from `CvListRow`'s existing `/cvs/${id}/edit` link (Dashboard), and should also work as the destination for Comparison Report's "Generate CV" and the Template Picker flow later — this task only needs to wire the Dashboard entry point that already exists.
